# gem
Simple retro-style voxel graphics library

* Low poly
* No curves
* No GPU
* No bloat

# Resources:

Abbreviations: GG = Graphics Gems by Glassner.

1. GG I: Backface culling (pp 346)
2. GG I: Digital line drawing (pp 99)
3. GG I: rendering fat lines on a raster grid (pp 114)
4. ray-triangle intersection
5. GG I: spheres-to-voxels conversion (pp 327)
6. GG I: box-sphere intersection (pp 335)
7. GG I: ray-box intersection (pp 395)
8. GG I: fast approximation to 3D Euclidean distance (pp 432)
